# Mixed Messages Codecademy Project

In this project, I built a message generator program that predicts the winner of the Premier League in a random year between 2030 to 2130. The program also confirms the winning points tally and how many league titles the winning team have now won after their victory.

 I put together my knowledge of functions, arrays and objects with my new understanding of Git version control and the command line to upload the finished project here on GitHub!
